# OtterFind

The Expo app lives at the repository root. The Spring Boot API remains in `api/`.

## Run the app

Install dependencies once:

```sh
npm install
```

Start Expo:

```sh
npm start
```

Scan the terminal QR code with Expo Go on Android, or press `a` to open an Android emulator. Use `npm run web` to launch the web version. If a physical device cannot reach the development server over Wi-Fi, use `npx expo start --tunnel`.

The Google and GitHub buttons are UI placeholders. OAuth and API requests are not connected yet.
